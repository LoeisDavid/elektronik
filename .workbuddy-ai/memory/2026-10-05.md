## Tweak lanjutan (permintaan user)
- **Kolom QTY diganti DISKON + VOUCHER.** Alasan domain: tiap unit fisik = 1 baris `itmdt` dengan `BC_OUT` unik, jadi qty SELALU 1 — stepper qty tidak berguna. Diskon/voucher per baris memang sudah ada di skema: `sts.POT_1` (diskon %) dan `sts.POT_R` (voucher Rp), plus di session cart (`discount`, `discount_voucher`).
  Kolom final: BARANG / HARGA / DISKON / VOUCHER / SUBTOTAL / AKSI. Angka konsisten: Subtotal Rp 14.246.000, Diskon -Rp 100.000, Voucher -Rp 50.000, Total Rp 14.096.000.
- **Ambiguitas dua tombol barcode dihapus.** Sebelumnya ada chip ikon barcode (latar biru, terlihat seperti tombol) + tombol "Scan". Sekarang ikon barcode jadi glyph abu-abu tanpa latar (affordance input), dan hanya ada SATU tombol navy: ikon kamera + label "Scan".
- **Board baru: `POS - Kasir / Scan Kamera (modal)`** (kloning board utama + dim overlay #0D1C43 @55% + kartu modal 760x610). Isi modal: judul "Scan Kamera", preview kamera gelap dengan bingkai sudut + garis scan + simulasi barcode, dropdown pemilih kamera, link "Ketik kode manual", hint "Tekan ESC untuk menutup", tombol "Batal".
- Catatan implementasi kamera: pakai `navigator.mediaDevices.getUserMedia({video:{facingMode:'environment'}})` + library decoder barcode (mis. `@zxing/browser`) yang membaca frame dari `<video>`. Wajib secure context — `localhost`/127.0.0.1 atau HTTPS; di HTTP biasa (mis. IP LAN) kamera diblokir browser. Scanner gun USB tetap jalur utama (bertindak sebagai keyboard: ketik kode + Enter ke input yang auto-focus), jadi modal kamera hanya fallback.
- Bug Penpot yang ditemukan & diperbaiki: `createShapeFromSvg` memakai viewBox 0 0 24 24, jadi path dengan koordinat > 24 TERPOTONG. Untuk elemen presisi (bracket sudut) lebih baik pakai rect daripada SVG.
